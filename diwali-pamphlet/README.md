# Poonam’s Food — Diwali Faral Pamphlet

Premium festive pamphlet for **Poonam’s Food** Diwali faral (Punawale).

## Open the pamphlet

Open `index.html` in a browser, or serve the folder:

```bash
cd diwali-pamphlet && python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
